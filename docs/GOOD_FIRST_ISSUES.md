# 10 Good First Issues for Community Contributors

You can post these 10 issues on GitHub with labels `good first issue` and `help wanted`:

1. **Add Piotroski F-Score (9-point financial health score)**:
   - Compute the 9 binary fundamental accounting criteria across profitability, leverage/liquidity, and operating efficiency.
2. **Add Altman Z-Score for Indian Manufacturing Companies**:
   - Implement the emerging markets modified Altman Z-Score formula to assess bankruptcy risk.
3. **Add Beneish M-Score for Earnings Manipulation Detection**:
   - Implement the 8 financial metric index to flag aggressive accounting or earnings manipulation.
4. **Support BSE SME and NSE Emerge Platform Tickers**:
   - Add ticker suffix resolution and handling for Indian SME board micro-caps.
5. **Add Cash Conversion Cycle (CCC) Metric**:
   - Compute DSO (Days Sales Outstanding) + DIO (Days Inventory Outstanding) - DPO (Days Payable Outstanding).
6. **Support Custom WACC Parameters in the CLI**:
   - Allow users to pass custom Equity Risk Premium (`--erp`) and Risk-free rate (`--rf`) via CLI options.
7. **Add Dividend Payout and Dividend Yield History**:
   - Compute historical 3-year dividend payout ratio and dividend yield trends.
8. **Add CLI Output in JSON format**:
   - Add `--json` flag to `indiequity ratios` and `indiequity dcf` for automated pipelines.
9. **Add Working Capital Requirement vs. Revenue Ratio**:
   - Calculate Net Working Capital as a percentage of Revenue to flag working capital strain.
10. **Add Historical Ratio Comparison Plot**:
    - Build a multi-year trend line chart showing ROCE and Operating Margin over 5 years.
